# Security reports

Please report suspected BaristaMatch vulnerabilities privately to
[hello@baristajobmatch.com](mailto:hello@baristajobmatch.com). Include the affected
page or component, the potential impact, and the smallest set of steps needed to
reproduce the problem. Use synthetic accounts and remove personal information
from screenshots or logs.

Do not put passwords, session tokens, API keys, private messages, payment details,
or another person's information in a public GitHub issue. If a credential may
have been exposed, identify the credential type and where it appeared without
copying its value.

We maintain the version deployed from the repository's `main` branch. A report
can also identify older releases so its impact can be assessed. This policy does
not authorize access to other users' accounts or data, destructive testing,
service disruption, or unsolicited automated scanning of production systems.

Security and dependency updates are reviewed through pull requests and automated
checks. Changes to production security settings and native app releases require
the owner's approval.
